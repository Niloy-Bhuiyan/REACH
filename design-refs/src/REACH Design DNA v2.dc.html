One language, two densities, zero ambiguity.

v2 keeps Concept A’s canvas, navy display type, violet / sage / apricot richness and substantial pixel-art identity. What changes is the rulebook: semantics are now single-valued, navigation matches on both platforms, working screens get their own density profile and components, and every state, motion and breakpoint is specified.

05

Pixel-art density by context

The universal floor is gone; identity is not.
BRAND MOMENTS Strong presence Focus, onboarding, auth, empty states, milestone celebrations. 10–18% of page area. Full scenery band 300–330px + 72–84px status objects + section glyphs.
NARRATIVE SCREENS Moderate, purposeful Roadmap, One Fix Away, Job Detail header. 5–10%. Header strip 120–200px, milestone/gap emblems at 48–72px, glyphs at section heads. Art must carry meaning (progress, gap type, verdict).
FUNCTIONAL SCREENS Low, glyphs only Discovery results, Resume editor, filters, settings, tables. 1–5%. 30–34px glyphs at section heads and tab labels; optional 80–120px header strip; zero art behind data, rows or forms.
NO-DATA STATES Art leads Empty results, no target yet, nothing to apply for today, failed run. Up to 25%. One scenery vignette + one sentence + one action. This is where personality does the emotional work.
Non-negotiable minimum: every screen carries the pixel wordmark plus at least one pixel glyph. A screen with zero pixel art fails review even in Working Mode. Still banned everywhere: mascots, robots, faces, AI pets, animated loops, HUD frames, XP bars, art behind numbers or dense text, mid-size per-row decoration, smoothed scaling. Scenery contrast limit: ≤ 55% contrast against canvas, masked to transparent before content begins, so navy type always dominates.

Interaction states & motion

STATESPECIFICATION
HoverRows/cards → background #F7F5FD, border → #DCD8EC. Filled buttons darken ~6% (#5A51C0 · #366B49 · #AE6828). No lift, no scale.
PressedDarken ~12%, scale .99, 80ms. Ripples and bounces are banned.
SelectedViolet tint fill + 1.5px #C3BCEC + 3px violet rule on the leading edge, and the label goes 600 weight.
Focus2px #574FC0 ring at 2px offset, radius + 2, visible on keyboard only. Never removed, never colour-only inside a dark surface (use #9AA0F0 there).
DisabledFill → #EDEAF7, label → #8A8FA8, border → #E7E4F0, no shadow, cursor not-allowed, and a reason string within 1 row.
Error2px #A33F28 border, #FBEDE9 fill, 13px #A33F28 message below with a word — never a red border alone.
EmptyScenery vignette + one sentence naming what is missing + exactly one action. Never a blank card, never a spinner.
LoadingSkeleton bars #EDEAF7 at the real row geometry, 1.2s shimmer; runs use the Activity Console instead. Max one spinner per screen, 20px, only for < 1s actions.
StaleApricot chip “Last verified 3 d ago” on the affected rows + a Re-verify action. Content stays visible; it is never silently hidden.
SuccessSage chip or row tint fading over 240ms + a plain-language confirmation. No confetti, no sound, no full-screen takeover.
Motion tokens Durations: 100 (chip), 120 (fade, tab), 180 (drawer), 220 (sheet), 240 (count-up, tint fade), 320 (progress). Easing: entering cubic-bezier(.2,.8,.2,1), exiting cubic-bezier(.4,0,1,1), progress linear. Discovery progression: each console event fades up 2px over 120ms, ≥ 300ms apart; the progress bar animates width 240ms; completion collapses the console to its summary line over 220ms. Opportunity Delta: the projected number counts up once over 240ms when it enters view, then the +n badge fades in over 120ms. Never loops, never re-runs on scroll. Roadmap progress: bar width 320ms; a completed milestone marker settles once, 240ms. Accepted resume edit: the after-text tints sage for 240ms, the row settles 160ms, the queue advances 120ms. Drawers / sheets: drawer translates 24px + fades 180ms with a 120ms backdrop; mobile sheet 220ms from the bottom edge; both trap focus and return it on close. Reduced motion: all translations and count-ups become instant; the console renders as a static list with the final counts; transitions collapse to ≤ 100ms opacity.
Motion never Looping ambient animation, floating artwork, parallax scenery, sparkle on AI output, animated mascots, bouncing CTAs, or anything that moves while the user is reading a number.

09

Asset hygiene

Production rules Transparent PNG only. No baked rectangular backing plates, no white boxes, no card-coloured fills behind a glyph — the art must sit on any tint. Debt cleared: the 17 icons extracted from the reference screenshots all carried a baked tinted backing and anti-aliased edges. They have been restored to true alpha and live at refs/i/px-*.png, which is what every screen now references. The opaque originals remain at refs/px-*.png and must not be used. Glyph family: 52 purpose-drawn glyphs at refs/i/g-*.png — authored on a 24×24 grid, exported 4× at 96px, hard edges, DNA palette, one-pixel outline. Regenerate or extend them from refs/glyphgen.js rather than hand-editing a PNG. Authoring: 32 / 64 / 96px canvases, exported at 2×, integer scaling only, image-rendering: pixelated. Outline is one pixel of #2E2A5A; no anti-aliasing, no drop shadow, no glow. One icon language: the pixel glyph set is the only icon system. No line-icon library, no emoji, no mixed sets on a screen — including nav, tabs, toolbars and empty states. Scenery: authored ≥ 720 × 360, desaturated toward lavender, ≤ 55% contrast vs canvas, always masked to transparent at the content edge. Naming: px-<domain>-<name>@2x.png, e.g. px-roadmap-milestone-done@2x.png. Scenery: scene-<screen>-<variant>.png.
Fallback ladder when art does not exist yet 1. Use the nearest existing motif from the same family (briefcase for opportunities, wrench for fixes, map for plans, locked case for blockers). 2. If none fits, ship the section with a type-only head — eyebrow label + Baloo title. A missing glyph is acceptable; a wrong glyph is not. 3. For a missing scenery band, use a flat canvas header at the same height rather than stretching or repeating an existing scene. 4. Never substitute an emoji, a stock illustration, a line icon or an AI-generated image in a different style. 5. The DNA v1 §09 backlog is closed — every entry on it has been drawn. Log any new gap in the asset inventory of the Final Handoff Index instead, and add the glyph to refs/glyphgen.js so the family stays reproducible.

Ship checklist v2

Mode-aware. All of column one, plus the column for the screen’s mode.
Every screen
Canvas #F5F3FB, surfaces #FBFAFE, no white or grey page. Nav is Focus · Discover · Roadmap · Resume · Profile, same on both platforms. One Baloo display anchor; type floors respected (12 / 14.5px, tabular numbers). Sage = Apply Now, apricot = One Fix Away, terracotta = Skip, violet = action. No exceptions. Every status colour paired with a word; every number over 24px has a derivation. Canonical terminology from §06 in every label and empty state. Pixel wordmark + ≥ 1 pixel glyph present; density inside the band for that context. Elevation tier chosen deliberately; shadows only on tier 3 and search. All ten interaction states defined for every interactive element and data region. Focus ring visible, 44×44 targets, AA contrast, reduced-motion path. Mobile version recomposed with bottom nav and sheets — never scaled.
Summary Mode also
≤ 9 surfaces, ≤ 3 per row, equal heights, one CTA per card. Lists show exactly 3 rows + “see all”. ≤ 4 chips per row; no tables, no toolbars, no tabs. Scenery band 300–330px; 72–84px objects in status cards. ≥ 34% whitespace; no fourth content tier. Target intent visible without scrolling.
Working Mode also
One dominant work area ≥ 55% of width; ≤ 2 scroll regions. Toolbar ≤ 5 controls + “More filters · n” sheet; result count always visible. Tables: white head, hairline rows, mono counts, hover tint, no zebra, no horizontal scroll on mobile. Detail opens in a drawer/sheet over the list; context is never lost. Scores appear as pairs with derivations (ATS Readiness + JD Match), never merged. AI output arrives as reviewable rows with accept / reject and a no-evidence state. Art ≤ 5% and none behind data; console only while a run is active. ≥ 22% whitespace, concentrated in the header and between panes.
