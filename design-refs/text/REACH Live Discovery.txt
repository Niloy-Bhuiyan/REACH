Profile
Working Mode decisions
No hero, no scenery band. Discovery earns a 120px page header instead: title, live count, target line, search. Pixel art appears only as the 30px section glyphs — the DNA’s functional band, 1–5%.
Results are the dominant work area at ~65% of the width, with a 372px rail for the run summary, Opportunity Delta, blocker tally and source provenance.
Console is the signature while running — full dark panel above the streaming results, thirteen observable events with real counts, progress bar, one Stop control. It never shows reasoning, only what the system did.
On completion it collapses to a single mono line — found, deduped, eligible, kept, verified — with Open log and Re-run. That line is the only dark surface left on the screen.
Four filters visible + “More filters · 3” plus sort and saved count, matching the Working Mode toolbar cap. Verdict tabs carry the counts; groups are collapsible with Apply Now expanded first.
Every row carries provenance: source, last-verified time in mono, evidence verdict (“3 of 3 met”) or the single blocker with its gap type, then Save and one verdict-coloured primary action.
Mobile is recomposed, not scaled. The rail disappears; its content becomes the collapsed strip, the tab counts and the sticky one-fix action. Rows become stacked cards with 44px Save / Open buttons.
Mobile console is a bottom sheet at 46% height with a Hide control, so the results it describes stay visible behind it — then it becomes the 10.5px strip under the search field once the run completes.
Still on the missing-asset list for this screen: a scanning/radar motif for the active run, dedicated source glyphs (career page, job board, referral), a “verified live” stamp and a freshness clock glyph. Section glyphs here reuse the existing briefcase / fix / skip motifs per the fallback ladder.
