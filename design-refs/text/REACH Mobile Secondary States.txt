State rules these six establish
An empty state names its cause and quantifies the remedy. “Posted under 3 days removes 51 of them”, then one loosening with the count it would return. Never a shrug.
Failure preserves and labels. Last good results stay on screen, stamped stale in apricot, explicitly excluded from the Delta until a run completes. The engine and the stage of failure are both named.
Verdict determines the action bar. Skip gets Hide / Show alternatives as its pair, with “Apply anyway” present but demoted to a text link — the product advises, it does not forbid.
Unavailable is never zero. JD Match with no JD reads “Not yet measured” on a dashed surface with an empty track — a 0% bar would be a false statement about the CV.
Completion reports against the prediction. Realised +9 against predicted +8, with the reason for the difference. The plan ends in applying, and the next plan stays queued rather than auto-starting.
Recoverable errors show the workaround already in effect. The invalid key is terracotta, but the fallback row says REACH-hosted is running and evidence is untouched.
Deliberately not redrawn, because each is a substitution inside a frame that already exists: Profile edit sheets (the Career Profile sheet pattern with a different field set), Discovery loading (the drawn console at 0 events), assistant scope variants beyond the four specimened, Roadmap skipped-step (locked row with a struck label), and Resume accepted / rejected diff rows (the drawn card with its state chip swapped).
